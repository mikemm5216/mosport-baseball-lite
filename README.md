# MOSPORT BASEBALL LIFE v1.1.0

從高中校隊起步，一路走向國際賽、選秀、職棒與退休的棒球人生遊戲。

## v1.1.0 更新重點

- 玩家介面改用棒球生涯語言，不再顯示機率、系統判定或內部計算提示。
- 首頁直接顯示球隊、層級、角色、背號、加入方式與代表隊經歷。
- 進入 CPBL 後會保留正式球隊、選秀年份、輪次、該輪順位、總順位、簽約金、背號與二軍起始角色。
- 非選秀進入職棒時，會明確顯示球團測試合格，不會捏造選秀順位。
- 高中階段加入 U-15／U-18 觀察、培訓、選拔、正式名單、國際賽與海外球探追蹤流程。
- 代表隊、傷病、訓練、角色、家庭、媒體、合約與關鍵對位都會停下來等待玩家選擇。
- 不同新生涯使用不同亂數起點，事件人物、順序、球隊與選秀結果都會改變。
- 同一事件版本同一球季最多出現一次，可在不同年份再次發生，但完整生涯最多三次。
- 同事件再次出現時會依年份、球隊、角色與人物改寫情境，不會原文重播。
- 同一事件家族不連續出現；代表隊、傷病與復健等合理事件鏈除外。

## PMV 與 TMV

- PMV 是球員長期棒球實力，包含各項能力、長期成績與累積履歷。
- TMV 是目前可用狀態，會受到手感、健康、疲勞、士氣、角色與教練信任影響。
- 遊戲只把兩者轉成玩家需要知道的能力、狀態與球隊安排；詳細運算留在存檔內。

## Mosport 歷史比賽情境

關鍵對位使用 Mosport 已提交的 MLB Statcast 情境資料，帶入局數、比分、出局數、壘況、球數與左右對位。歷史賽果不會替玩家決定結果；玩家先選策略，再由球員當下能力與狀態完成比賽。

## 存檔

v1.1.0 使用獨立存檔。請建立新生涯，避免舊版本資料影響球隊、代表隊與事件紀錄。

## 部署

GitHub 根目錄只需保留 `index.html` 與 `README.md`，即可作為靜態網站部署。
