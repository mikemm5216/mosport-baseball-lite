# MOSPORT BASEBALL LIFE v1.0.2

一個由高中一路走到大學、業餘、職棒與退休的年度制棒球人生遊戲。

## v1.0.2：直接呈現棒球人生的發展

- 選擇後直接顯示發生的事情，不再用系統狀態詞代替情節。
- 情節標題與敘事成為畫面主體；玩家選了什麼及造成的能力、身體、關係或市場影響放在下方。
- 關鍵對位直接呈現球員執行與比賽發展，不再用工程式文字說明資料如何記錄。
- 全面改用棒球生涯語言，移除結果畫面的英文後台標籤。

## 玩家選擇驅動的完整球季

- 不再固定每季 3 張事件卡、3 次關鍵對位。
- 每季依聯盟階段、球隊角色、教練信任、疲勞與健康形成不同進程。
- 一般比賽與時間可以在背景推進，但不會偽裝成事件卡。
- 只要畫面出現事件，遊戲一定停下等待玩家決定；沒有選擇就不會產生結果。
- 訓練、角色、隊內、家庭、健康、媒體、市場與合約等重要事件由玩家選擇。
- 傷病不是一行狀態變化，而是「受傷當下 → 檢查診斷 → 手術／保守治療／第二意見 → 復健節奏 → 回場測試」的連續選擇。
- 例行賽關鍵對位會依上場機會自然出現；季後賽與冠軍賽另行追加。
- 同一季優先不重複相同事件；關鍵對位不會連續出現相同完整情境。
- 重要選擇與對位結果會寫入球季報告、生涯紀錄與匯出存檔。
- 跨季疲勞、健康、手感與士氣依年齡和休季恢復動態變化，不再固定重設。

## 既有核心

- PMV 表示球員自己的能力；TMV 另外綜合能力、手感、健康、士氣、角色信任、隊友關係、疲勞與傷勢，決定球隊願意給多少機會。
- 球數、壘況、出局數、分差、左右對位與球員狀態會改變關鍵對位選項。
- 選擇前只顯示符合球員當下狀態的風險提示，不公開後台機率；選擇後才揭曉結果。
- 關鍵對位把「判讀品質、球員執行、球隊勝負」分開記錄；正確判讀即使執行失敗，仍可留下成長證據。
- 高中畢業能力達標可直接參加職棒選秀；大一至大四每年都能投入選秀。
- 公開標籤記錄選擇、角色與重要成就。
- 投手與野手各有 16 個歷史原型隱藏標籤，每季最多覺醒一個。
- 隱藏標籤覺醒後，會對相符的關鍵對位提供小幅加成。

## Mosport 歷史資料種子

- 關鍵情境取自 Mosport 儲存庫已提交的 `data/migrated/source-mirror/mlb/data/statcast_cache/statcast_2024_04.parquet`。
- 只使用賽前可知的情境欄位：日期、局數、上下半局、出局數、壘況、球數、比分與左右對位。
- 歷史比賽的實際結果只保留作資料來源追溯，絕不拿來替玩家選擇評分或直接決定結果。
- 每次對位會留下 seed ID、完整情境簽章、玩家選擇、判讀品質、執行結果與球隊結果，並避免近期重複同一完整情境。
